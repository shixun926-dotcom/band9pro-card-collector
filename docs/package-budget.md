# 1 MB 体积预算

## 硬限制

- 整个快应用包不超过 `1,048,576` 字节。
- 单张卡面不超过 `51,200` 字节。
- 单张卡面的建议目标不超过 `35 KB`。

“每张不超过 50 KB”不能保证整包不超过 1 MB。若代码和公共资源占用
250 KB，则 20 张 50 KB 卡面已经达到 1.25 MB。因此必须同时限制卡片数量和
平均卡面体积。

## 推荐配置

| 卡片数量 | 平均卡面预算 | 卡面总计 | 预留其他资源 |
| ---: | ---: | ---: | ---: |
| 24 | 20 KB | 480 KB | 约 550 KB |
| 30 | 18 KB | 540 KB | 约 490 KB |
| 36 | 15 KB | 540 KB | 约 490 KB |
| 40 | 12 KB | 480 KB | 约 550 KB |

当前首版采用 24 张卡，并使用程序生成的压缩 PNG 占位卡面。正式卡面替换时，
建议统一输出为：

- 尺寸：`180 x 240` 或 `168 x 224`。
- 格式：WebP 或调色板 PNG。
- 单张目标：不超过 20 KB。
- 不把卡框、稀有度光效和名称烘焙到每张图里。
- 公共卡框、角标和光效由代码绘制或使用一张共享资源。

## 其他体积规则

- 不打包字体文件，使用系统字体。
- 不打包源 PSD、Procreate、Aseprite 或未压缩原图。
- 背景优先使用纯色、CSS 绘制或一张共享背景图。
- 音效若加入，整包建议不超过 60 KB，并使用低采样率单声道。
- 构建后必须运行：

```powershell
npm run check:budget
```

检查脚本会枚举 `app/` 下的实际文件，分别报告整包体积、卡片平均体积和最大
卡片体积。
